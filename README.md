# logica-programacao

Exercícios de lógica de programação desenvolvidos em Python.

## Tecnologias utilizadas
- Python 3

---

# 1. Calculadora Simples

Este programa em Python funciona como uma calculadora básica no terminal.

## Funcionalidades
- Solicita ao usuário dois números;
- Exibe um menu de operações:
  - Soma
  - Subtração
  - Divisão
  - Multiplicação
- Mostra o resultado da operação escolhida;
- Permite realizar novas operações sem precisar reiniciar o programa.

## Observações
- Caso o usuário escolha uma opção inválida no menu, o programa exibirá a mensagem `Opção inválida!`;
- Após cada operação, o usuário poderá escolher entre reiniciar ou encerrar o programa.

# 2. Par ou Ímpar

Este programa em Python verifica se o número escolhido pelo usuário é par ou ímpar.

## Funcionalidades
- Solicita ao usuário um número;
- Verifica se o número é par ou ímpar;
- Exibe o resultado na tela;
- Permite realizar novas verificações sem precisar reiniciar o programa.

---

# 3. Tabuada

Este programa em Python mostra ao usuário a tabuada de 1 a 10 do número escolhido.

## Funcionalidades
- Solicita ao usuário um número;
- Exibe a tabuada de 1 a 10 do número informado;
- Permite realizar novas operações sem precisar reiniciar o programa.
